# Photos cancellation and expired-upload cleanup

`POST /api/photos/uploads/abort` on the Photos app requires a valid ProductSession and personal Space write access. It accepts only `uploadId`; submitted object keys never authorize deletion. A conditional manifest write marks a pending upload `aborting`, excluding completion and presign renewal. It returns `202` with `{ cancelled: true, cleanupPending: true, cleanupAfter: ISODate }`. Repeated requests return the same queued outcome while the ledger remains pending cleanup. Completed/completing, blocked or retired manifests return `409`.

The request does not delete R2 objects. The `expiresAt` field includes the conservative 24-hour signed-PUT grace and any renewal; physical deletion starts only after it expires. A future caller cutoff cannot bypass the current clock. The shared database repository owns the filter, five-minute conditional lease, reference checks, retry state and final ledger removal. The Photos app supplies an S3 storage adapter; it does not import Drive.

The authenticated hourly `/api/cron/cleanup-photo-uploads` processes at most 100 due pending/aborting manifests. It excludes live leases and one-minute retry cooldowns. Manifest keys must match the owning account's server-generated opaque key format and remain unreferenced across products and Bin. Referenced or malformed manifests become `blocked`. The adapter performs exact `DeleteObjects`, checks per-key errors, and confirms every key is absent with `HeadObject`. Only the current lease can then delete its ledger. Failed storage/routing/HEAD attempts retain the ledger and return a retry result; the cron returns `500` when any attempt fails.

No Usage or bucket counters change during this cleanup: pending Photos uploads were never committed or charged. There is no stored `aborted` terminal state or TTL index. Disposable development manifests should be reset/reseeded when changing this contract; no production-data migration is needed. Tests use a disposable replica set and mocked S3 storage. No live R2 bucket, CORS policy or deployed scheduler was exercised.
